The interrexx Language Specification

::ANNOTATE

::ANNOTATE PACKAGE | CLASS name | METHOD name | ATTRIBUTE name | CONSTANT name | ROUTINE name {annotation value}...

rexxref: Directives > ::ANNOTATE

::ANNOTATE attaches notes to the parts of a package. A note is an annotation, a name with a text as its value, and a program that holds the object of a package, class, method or routine can read the annotations that were declared for it. The interpreter does nothing with them: no annotation name has a meaning of its own, so they carry information for tools and for the program itself. This page specifies what the directive may name, the form of the names and values, and which annotations a program finds. The methods that read and change annotations belong to the classes chapter, and the examples use only ANNOTATION and ANNOTATIONS, and the methods that reach an object.

The form

[dir.annotate.syntax]

After the directive word comes a kind word, in any case: PACKAGE, CLASS, METHOD, ATTRIBUTE, CONSTANT or ROUTINE. Every kind but PACKAGE then has a target name, a symbol or a string, and the rest of the clause is a list of annotations, each a name and a value. The list may be empty. A missing kind raises SYNTAX 20.924, a word that is no kind 25.928, and a missing target name 19.925. The directive takes no code: a clause after it that is not a null clause raises SYNTAX 99.916, as the section rule says, so that the directive ends the code of the method or routine before it. These faults are found when the program is read, so as the read rule says a program file with one writes nothing and exits with 256 minus the error number, 236 for 20.924.

call try '::annotate'
call try '::annotate frob x a b'
call try '::annotate class'
call try '::annotate package'
call try '::annotate package a b', '', '-- a comment', '::class k'
call try '::class k', '::annotate CLASS K a b; ::annotate class k c d'
call try '::class k', '::method m', '  return 1', '::annotate method m a b'
call try '::class k', '::method m', '::annotate method m a b', '  return 1'
exit
try:
  signal on syntax name e
  src = .array~new
  do i = 1 to arg()
    src~append(arg(i))
  end
  p = .package~new('spec-dir-annotate-syntax', src)
  say src~makestring('l', ' / ') '=> ok'
  return
e: say src~makestring('l', ' / ') '=>' condition('o')~code
  return

[dir.annotate.value]

Each annotation is a name followed by a value. The name is a symbol, which is taken in upper case and never looked up as a variable. A name that is not a symbol, a string or an operator for instance, raises SYNTAX 20.919. The value is a string, a symbol or a number with an optional sign, and is kept as text: a string as written and a symbol in upper case, which includes a number that is written as a symbol such as 1e3. A sign before a number is kept and joined to it, also when a blank stands between them, and the number is kept as written. A symbol may hold periods, as .abc and a.b do. A value in parentheses raises 19.923, and so does a sign before anything but a number: before a sign, a string or a symbol that is no number. A list with an unpaired word raises 19.924. A name given twice, in one directive or in several, keeps the value that comes last in text order, and the other names are kept. The names and values do not depend on one another or on any variable of the program.

p = .context~package
a = p~annotations
do name over a~allindexes~sort
  say name '=' '['a[name]']'
end

::annotate package sym abc env .abc dotted a.b num 007 exp 1e3 empty ""

What is annotated

[dir.annotate.target]

The target of a CLASS, ROUTINE, METHOD, ATTRIBUTE or CONSTANT annotation is an element that an earlier directive of the same package declared, found by its name with case ignored, whether the target was written as a symbol or as a string. A class or a routine is found among those declared before the directive, however many directives lie between. A method, an attribute or a constant is found only among those declared in the section of the most recent ::CLASS, or, before any class, among the methods that no class holds. A target that is not found, which includes one that is declared later, in another class, or by another package that was required or supplied by the interpreter, raises SYNTAX 99.945. The directive with no annotation is checked in the same way. The error is found when the program is read.

call try '::annotate class k a b'
call try '::annotate class k'
call try '::class k', '::annotate class k a b'
call try '::class k', '::annotate class "K" a b'
call try '::annotate class k a b', '::class k'
call try '::class k', '::class l', '::annotate class k a b'
call try '::class k', '::annotate class k'
call try '::class k', '::annotate class .k a b'
call try '::annotate class object a b'
call try '::routine r', '::class k', '::annotate routine R a b'
call try '::annotate routine r a b', '::routine r'
call try '::class k', '::method m', '::annotate method M a b'
call try '::class k', '::method m', '::class l', '::annotate method m a b'
call try '::method m', '::annotate method m a b'
call try '::method m', '::class k', '::annotate method m a b'
exit

[dir.annotate.kind]

The kind word says which declarations the name is looked for in. CLASS finds a class, ROUTINE a routine and PACKAGE needs no name and annotates the package itself. METHOD finds a method that a ::METHOD declared, and also the method of an attribute or a constant, whose names are the attribute's name, with an equals sign for a setter, and the constant's name. ATTRIBUTE finds an attribute that ::ATTRIBUTE or the ATTRIBUTE option of ::METHOD declared and no other method, and the annotation is attached to both of the methods of the attribute that exist. CONSTANT finds a constant. An element is not found by the wrong kind word, and the error is SYNTAX 99.945. A name that holds an equals sign has to be written as a string. A method that was declared with the CLASS option, and an attribute that was, are found in the same way as the others. When a class has an instance method and a class method of one name, the annotation goes to the instance method, whichever of the two directives comes first, and the class method has none. A class method is annotated when no instance method has the name.

call try '::class k', '::attribute m', '::annotate attribute m a b'
call try '::class k', '::attribute m', '::annotate method m a b'
call try '::class k', '::attribute m', '::annotate method "m=" a b'

call try '::class k', '::method m', '::annotate attribute m a b'

call try '::class k', '::constant m 1', '::annotate attribute m a b'
call try '::class k', '::method m', '::annotate constant m a b'
call try '::routine r', '::annotate method r a b'
call try '::routine r', '::annotate class r a b'
call try '::routine r', '::annotate package r a b'
exit

Reading the annotations

[dir.annotate.read]

The annotations of an element are kept with its object. The ANNOTATION message of the object of a package, class, method or routine, with an annotation name, returns the value as a string, or .nil when the element has no annotation of that name, and the name is looked up in upper case. The ANNOTATIONS message returns a table of all of them indexed by name. The annotation of an attribute is found on both of its methods, and that of a constant on the method of the constant. An annotation is not inherited: a class that names an annotated class as its superclass has none of its annotations, and the same name on a class and on its method are two separate annotations. A copy of an annotated routine or method keeps its annotations.

p = .context~package
say 'package' p~annotation('maint') p~annotations~items
say 'class' .k~annotation('X') .k~annotation('y') .k~annotations~items
say 'sub' .sub~annotations~items
m = .k~method('M')
say 'method' m~annotation('v') m~annotation('x') m~annotations~items
say 'copy' m~copy~annotation('V')
say 'attribute' .k~method('AT')~annotation('P') -
  .k~method('AT=')~annotation('P')
say 'constant' .k~method('C')~annotation('P')
r = p~findroutine('R')
say 'routine' r~annotation('p') r~copy~annotation('P') r~annotations~items
say 'none' (p~annotation('nothing') == .nil)
