The interrexx Language Specification

The rxmath library

rexxref: Rexx Mathematical Functions Library (rxmath) > Functions

The library rxmath provides the mathematical functions of a program that works on binary floating-point numbers: square root, exponential, logarithm, power, the hyperbolic functions, the trigonometric functions and their inverses. This page holds what every function of the library shares: how the functions are made available, how their arguments are read, and how a result is written. The trigonometric page holds the functions of an angle.

Every function reads its number arguments as 64-bit binary floating-point numbers, makes one call of the function of that name on them, and writes the answer as a number with a given count of significant digits. A result is as exact as a 64-bit binary floating-point number is, and no more.

The examples call the functions after one of them has been made available, as the availability rule says.

Availability

[rxmath.index.available]

The functions of the library are not provided from the start of a program. They are made available by RXFUNCADD of the name of any one of them with the library name rxmath, or by a ::requires directive with the LIBRARY keyword, and from then on every function of the library can be called, as name(arguments) or by CALL, with its name in any case. A name is not a method of String: sending it to a string as a message raises SYNTAX 97.1. A call of a function that the library has not made available raises SYNTAX 43.1. The functions are MathLoadFuncs, MathDropFuncs, RxCalcPi, RxCalcSqrt, RxCalcExp, RxCalcLog, RxCalcLog10, RxCalcSinH, RxCalcCosH, RxCalcTanH, RxCalcPower, RxCalcSin, RxCalcCos, RxCalcTan, RxCalcCotan, RxCalcArcSin, RxCalcArcCos and RxCalcArcTan. RXFUNCDROP of one of them removes nothing: the library stays available until the program ends.

say rxfuncquery('RxCalcSqrt') rxfuncquery('RxCalcPi')
say rxfuncadd('RxCalcPi', 'rxmath')
say rxfuncquery('RxCalcSqrt') rxfuncquery('RxCalcPi') rxfuncquery('MathLoadFuncs')
say RxCalcSqrt(25) RXCALCSQRT(25) 'rxcalcsqrt'(25)
call RxCalcSqrt 16
say result
say rxfuncdrop('RxCalcPi') rxfuncquery('RxCalcPi')
signal on syntax name a
say 'x'~RxCalcSqrt

Loading and dropping

[rxmath.index.load]

MathLoadFuncs and MathDropFuncs exist for programs that were written for a system where the library had to be loaded and dropped. Each answers the null string and changes nothing: the functions are available without a call of either, and after any number of calls. MathLoadFuncs called with an argument, of any value, writes a banner on standard output before it answers. The banner names the library and is not specified (Deviation 96), and MathLoadFuncs called without one writes nothing. MathLoadFuncs takes at most one argument and MathDropFuncs none: more raise SYNTAX 88.922.

call lineout 'c1zqm1.rex', "say '['MathLoadFuncs('x')']'"
call lineout 'c1zqm1.rex', "say '['MathLoadFuncs()']'"
call lineout 'c1zqm1.rex', "say '['MathDropFuncs()']'"
call lineout 'c1zqm1.rex', "::requires 'rxmath' library"
call lineout 'c1zqm1.rex'
address system 'rexx c1zqm1.rex' with output stem out.
say pos('rxmath', out.1) > 0
do i = out.0 - 1 to out.0
  say out.i
end
call sysfiledelete 'c1zqm1.rex'

Arguments

[rxmath.index.args]

The functions follow the native call rule, as the RexxUtil functions do. A required argument that is not given, or is omitted, raises SYNTAX 88.901. An argument past the last one of the function raises SYNTAX 88.922, and the count is checked before the arguments are read. An omitted place at the end of the call adds nothing to the count, so RxCalcSqrt(4,,) is a call with one argument. An argument that is an object other than a string is replaced by the string that its request with the argument STRING answers, and an object that has none raises SYNTAX 88.909.

call try "RxCalcSqrt(,)"

[rxmath.index.number]

An argument that the page of a function calls a number is read as a 64-bit binary floating-point number. A Rexx number is read at the precision of that format whatever NUMERIC DIGITS is in force: blanks before and after it, a sign and an exponent are allowed, and a number too large for the format is the infinity of its sign. Besides numbers, the three strings nan, +infinity and -infinity, in lower case and exactly so, are read as the values they name. Any other string, the null string included, raises SYNTAX 88.921, and so does an object whose string value is none of these.

Precision

[rxmath.index.precision]

The last numeric argument of most functions is the precision: the number of significant digits of the answer. It is optional. An argument given is a whole number that is above 0, and written as any number that has a whole value is allowed, as 5.0, ' 5 ' and 5E0 are; anything else raises SYNTAX 88.905, which a number that has a fraction, a number below 1 and a string that is no number all do. A precision above 16 is 16: no answer has more digits than a 64-bit binary floating-point number has. An omitted precision is the value of NUMERIC DIGITS of the program that calls the function, again at most 16. The precision does not change what is calculated, only how many digits of the result are kept, rounded.

say RxCalcSqrt(2) RxCalcSqrt(2, 1) RxCalcSqrt(2, 5) RxCalcSqrt(2, 16) RxCalcSqrt(2, 17) RxCalcSqrt(2, 1000)

Results

[rxmath.index.result]

The answer of a function is the result of its calculation, rounded to the precision and written as the result of arithmetic is written at a NUMERIC DIGITS of that precision, so that it takes the form with an exponent where those rules do. A result that no number has is one of the three strings nan, +infinity and -infinity. The domain of a function is that of the function of the same name for 64-bit binary floating-point numbers: a function that is not defined for its argument answers nan, and an overflow answers an infinity. The answer is a string, not a number that carries a precision of its own, and a program reads it as it reads any string of digits.

say RxCalcSqrt(2) RxCalcExp(1) RxCalcExp(1, 3) RxCalcExp(0)
say RxCalcExp(100) RxCalcExp(100, 16) RxCalcExp(-100)

Square root, exponential, logarithms and power

[rxmath.index.unary]

RxCalcSqrt(x [, precision]) answers the square root of x, RxCalcExp(x [, precision]) answers e raised to the power x, RxCalcLog(x [, precision]) answers the natural logarithm of x, and RxCalcLog10(x [, precision]) the logarithm of x to the base 10.
