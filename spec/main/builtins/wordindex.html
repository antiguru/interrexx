The interrexx Language Specification

WORDINDEX

WORDINDEX(string, n)

ANSI: 9.3.26; rexxref: Functions > Built-in Functions > WORDINDEX

WORDINDEX answers where in a string one of its words begins, as a character position. Words are those of the word rule.

Arguments

[bif.wordindex.method]

WORDINDEX is a builtin that runs as a String method, and string, its first argument, is the receiver. string is a string and n is a word number. The arguments are checked in the order the conventions give, and the argument count by the builtin call rules: both are required and two is the most.

signal on syntax name a
say wordindex('a b', -2)
a: say condition('o')~code
signal on syntax name b
say wordindex('a b', '')
b: say condition('o')~code
signal on syntax name c
say wordindex(, 1)
c: say condition('o')~code
signal on syntax name d
say wordindex('a b', 1, 1)
d: say condition('o')~code

93.924
40.12
40.5
40.4

The result

[bif.wordindex.result]

When string has a word n, WORDINDEX returns the position in string of the first character of that word. The position counts characters of string from its first, so whitespace before the word, and the words and whitespace before that, all count toward it. The answer is written as a count, and whether it is a new object is not specified.

say wordindex('red  green blue', 2) wordindex('  red', 1),
    wordindex('09'x || 'red', 1) wordindex('a  bb  ccc', 3)

6 3 2 8
[bif.wordindex.past-end]

When n is greater than the number of words in string, the result is 0. This holds for every n past the last word that passes its check.

say wordindex('red green', 3) wordindex('red green', 999999999999999999)

0 0
[bif.wordindex.empty]

When string has no words, the null string or a string of only whitespace among them, the result is 0 for every n that passes its check.

say wordindex('', 1) wordindex('  ' || '09'x, 1)

0 0
