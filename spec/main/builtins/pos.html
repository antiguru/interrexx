The interrexx Language Specification

POS

POS(needle, haystack [, start [, length]])

ANSI: 9.3.16; rexxref: Functions > Built-in Functions > POS (Position)

POS searches a string for another string and answers the position of the first character of the first occurrence, or 0 when there is none. A starting position and a length can confine the search to a stretch of the string. LASTPOS searches from the other end.

Arguments

[bif.pos.method]

POS is a builtin that runs as a String method, and haystack, its second argument, is the receiver; needle, start and length become the message's arguments, in that order. needle and haystack are strings, start is a position and length is a length. The arguments are checked in the order the conventions give, and the argument count by the builtin call rules: two are required and four is the most.

say pos('ter', 'winter') 'winter'~pos('ter')
signal on syntax name a
say pos('a')
a: say condition('o')~code
signal on syntax name b
say pos('a', 'a', 1, 1, 1)
b: say condition('o')~code
signal on syntax name c
say pos(, 'a')
c: say condition('o')~code
signal on syntax name d
say pos('a', 'a', 0)
d: say condition('o')~code
signal on syntax name e
say pos('a', 'a', 1, -1)
e: say condition('o')~code
signal on syntax name f
say pos('a', 'a', 'x')
f: say condition('o')~code
signal on syntax name g
say pos('a', 'a', 0, 'x')
g: say condition('o')~code
signal on syntax name h
say pos('a', 'a', 0, -1)
h: say condition('o')~code

[bif.pos.start.default]

When start is omitted, it is 1: the search begins at the first character of haystack.

say pos('a', 'banana') pos('a', 'banana', ) pos('a', 'banana', 3)

2 2 4
[bif.pos.length.default]

When length is omitted, the search runs to the end of haystack.

say pos('a', 'banana', 3) pos('a', 'banana', 3, ) pos('a', 'banana', 3, 100)

4 4 4

The result

[bif.pos.result]

Let n be the length of haystack and m the length of needle. The characters that the search covers are those at the positions from start through start + length - 1 (through n when length is omitted), and at no position beyond n; this is the window, and it holds no characters when start is greater than n or length is 0. When m is at least 1, POS returns the smallest position k such that the m characters of haystack from position k on all lie in the window and are equal under == to needle. When there is no such k, the result is 0. A needle with no characters is the case of its own rule. The answer is written as a count, and whether it is a new object is not specified.

say pos('ter', 'winter') pos('q', 'winter') pos('i', 'winter'),
    pos('winter', 'winter')
say pos('aa', 'aaa') pos('aa', 'aaa', 2) pos('ana', 'banana') pos('ana', 'banana', 3)
numeric digits 3
say pos('y', copies('x', 1234) || 'y')

[bif.pos.window]

An occurrence is found only when all of it lies in the window: one that begins in the window but ends past its last position is not found, and neither is one that begins before start. So length bounds where the occurrence ends as well as where it begins.

say pos('an', 'banana', 1, 3) pos('an', 'banana', 1, 2) pos('an', 'banana', 2, 2),
    pos('an', 'banana', 3, 3)
say pos('ana', 'banana', 2, 3) pos('ana', 'banana', 2, 2) pos('ana', 'banana', 3, 5),
    pos('na', 'banana', 5, 2) pos('na', 'banana', 5, 1)
say pos('n', 'banana', 3, 1) pos('n', 'banana', 2, 1) pos('n', 'banana', 1, 2),
    pos('n', 'banana', 1, 3)

2 0 2 4
2 0 4 5 0
3 0 0 3
[bif.pos.length.zero]

When length is 0, the window holds no characters and the result is 0, for every needle and haystack. -0 is 0.

say pos('a', 'banana', 1, 0) pos('a', 'banana', 2, '-0') pos('', 'banana', 1, 0)

0 0 0
[bif.pos.past-end]

When start is greater than the length of haystack, the result is 0, for every start that passes its check. A start equal to the length of haystack searches the last character alone. A length that reaches past the end of haystack is the same as one that reaches exactly to it.

say pos('a', 'banana', 6) pos('a', 'banana', 7) pos('a', 'banana', 100),
    pos('a', 'banana', 999999999999999999)
say pos('a', 'banana', 6, 1) pos('a', 'banana', 7, 1) pos('a', 'banana', 6, 100),
    pos('a', 'banana', 1, 999999999999999999) pos('a', '', 1, 100)

6 0 0 0
6 0 6 2 0
[bif.pos.empty-needle]

When needle has no characters, the result is 0 for every haystack, the null string included. start and length are still checked, as a position and a length always are.

say pos('', 'banana') pos('', '') pos('', 'banana', 3, 2) pos('', 'banana', 100)
signal on syntax name a
say pos('', 'banana', 0)
a: say condition('o')~code
signal on syntax name b
say pos('', 'banana', 1, -1)
b: say condition('o')~code

0 0 0 0
93.924
93.923
[bif.pos.empty-haystack]

When haystack is the null string, the result is 0 for every needle and for every start and length that pass their checks.

say pos('a', '') pos('a', '', 1) pos('a', '', 1, 0) pos('', '')

0 0 0 0
[bif.pos.exact]

Two characters are equal only when they are the same byte. Case matters, whitespace in needle and haystack is compared like any other character, no numeric comparison is made, and '00'x and the other control characters take part like all the rest. A needle longer than haystack is never found.

say pos('A', 'banana') pos('a b', 'x a b') pos('a  b', 'x a b'),
    pos('a' || '09'x || 'b', 'a b') pos('1', '01') pos('1.0', '1')
say pos('00'x, 'a' || '00'x || 'b') pos('0a'x, 'a' || '0a'x) pos('abc', 'ab')

0 3 0 0 2 0
2 2 0
[bif.pos.string-form]

A needle or haystack that is a number, or an object other than a string, is replaced by its string, and POS works on the characters of that string as they are written.

say pos(1, 'a1') pos('.', 3.14) pos('an Object', .object~new)

2 2 1

Note. The ANSI draft (9.3.16) has no length argument, and defines POS by comparing the needle with each stretch of the haystack of its length from start on. Without length that gives the answers above, 0 for a start past the last place the needle fits included. It also returns 0 for a needle with no characters.
