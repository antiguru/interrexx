The interrexx Language Specification

VERIFY

VERIFY(string, reference [, option] [, start] [, length])

ANSI: 9.3.24; rexxref: Functions > Built-in Functions > VERIFY

VERIFY scans a string, or a run of its characters, for the first character that is not in a set of reference characters, or, with the Match option, for the first one that is, and answers its position.

Arguments

[bif.verify.method]

VERIFY is a builtin that runs as a String method, and string, its first argument, is the receiver; the other four become the message's arguments, in their order. string and reference are strings, option is an option, start is a position, and length is a length. The arguments are checked in the order the conventions give, and the argument count by the builtin call rules: two are required and five is the most.

say verify('a1', 'a') 'a1'~verify('1', 'M')
signal on syntax name a
say verify('abc', 'a', , 0)
a: say condition('o')~code
signal on syntax name b
say verify('abc', 'a', , 1, -1)
b: say condition('o')~code
signal on syntax name c
say verify('abc', 'a', , 'first')
c: say condition('o')~code
signal on syntax name d
say verify('abc', 'a', , 1, 1, 1)
d: say condition('o')~code
signal on syntax name f
say verify('abc', , 'M')
f: say condition('o')~code

[bif.verify.option]

option selects what VERIFY scans for, by its first character alone, in either case: N or n selects Nomatch, and M or m selects Match. Only that character decides; option may go on with any characters, and they change nothing. When option is omitted, it is Nomatch.

say verify('xy', 'x') verify('xy', 'x', 'n') verify('xy', 'x', 'Nope'),
    verify('xy', 'y', 'm') verify('xy', 'y', 'Many') verify('xy', 'y', 'M 1')

2 2 2 2 2 2
[bif.verify.option.check]

An option whose first character is not one of those four, and an option that is the null string, raise SYNTAX 93.915. This is a range check: it runs after every argument has passed its form check, and before the range checks of start and length. It is made whatever string and reference are.

signal on syntax name a
say verify('abc', 'a', 'Y')
a: say condition('o')~code
signal on syntax name b
say verify('abc', 'a', '')
b: say condition('o')~code
signal on syntax name c
say verify('abc', 'a', ' M')
c: say condition('o')~code
signal on syntax name d
say verify('', '', 'Z')
d: say condition('o')~code
signal on syntax name f
say verify('abc', 'a', 'Y', 'z')
f: say condition('o')~code
signal on syntax name g
say verify('abc', 'a', 'Y', 0)
g: say condition('o')~code

[bif.verify.start.default]

When start is omitted, it is 1: the scan starts at the first character of string.

say verify('aab', 'a', , ) verify('aab', 'a', , 1)

3 3
[bif.verify.length.default]

When length is omitted, the scan runs from position start to the end of string.

say verify('x--y', '-', , 2) verify('x--y', '-', , 2, 2)

4 0

The result

[bif.verify.nomatch]

With Nomatch, when start is at most LENGTH(string) and reference is not the null string, VERIFY returns the smallest position i from start to start + length - 1, and at most LENGTH(string), such that the character of string at i does not occur in reference, and 0 when every character in that run occurs in it.

say verify('cafe', 'efac') verify('ca-fe', 'efac'),
    verify('ab-cd', 'abcd', 'N', 4) verify('ab-cd', 'abcd', 'N', 2, 1)

0 3 0 0
[bif.verify.match]

With Match, when start is at most LENGTH(string) and reference is not the null string, VERIFY returns the smallest position i in the same run such that the character of string at i occurs in reference, and 0 when no character in that run occurs in it.

say verify('to be', ' ', 'M') verify('to be', 'xyz', 'M'),
    verify('x.y.z', '.', 'M', 3) verify('x.y.z', '.', 'M', 3, 1)

3 0 4 0
[bif.verify.exact]

A character occurs in reference only when reference holds that same character, byte for byte: case matters, and whitespace, control characters and '00'x are characters like any other. The order of reference and characters repeated in it make no difference.

say verify('ABC', 'abc') verify('a' || '00'x || 'b', 'ba') verify('a b', 'ba  ab'),
    verify('tab' || '09'x, 'bat', 'M') verify('tab' || '09'x, 'bat')

1 2 0 1 4
[bif.verify.past-end]

When start is greater than LENGTH(string), the result is 0, for every reference, and every option, start and length that pass their checks.

say verify('abc', 'x', 'N', 4) verify('abc', 'b', 'M', 999999999999999999),
    verify('abc', '', 'N', 4)

0 0 0
[bif.verify.empty-string]

When string is the null string, every start is past its end, so the result is 0, for every reference, and every option, start and length that pass their checks.

say verify('', 'a') verify('', '') verify('', 'a', 'M') verify('', '', 'N', 3)

0 0 0 0
[bif.verify.empty-reference]

When start is at most LENGTH(string) and reference is the null string, the result is start with Nomatch and 0 with Match. This holds for every length that passes its check, 0 included: no character of string is examined.

say verify('abc', '') verify('abc', '', 'N', 3) verify('abc', '', 'N', 2, 0),
    verify('abc', '', 'M') verify('abc', '', 'M', 2)

1 3 2 0 0

Note. The Nomatch answer for a length of 0 follows the reference manual, which gives start for a null reference without a condition on length; the ANSI draft has no length argument.

[bif.verify.length.zero]

When length is 0 and reference is not the null string, the run has no characters and the result is 0, with either option.

say verify('abc', 'x', 'N', 1, 0) verify('abc', 'a', 'M', 1, 0)

0 0

Note. VERIFY's answer, a position or 0, is a count: it is written as a count, and whether it is a new object is not specified.
