The interrexx Language Specification

DATATYPE

DATATYPE(string [, type])

ANSI: 9.3.8; rexxref: Functions > Built-in Functions > DATATYPE

DATATYPE examines the characters of a string. Called with the string alone, it names the string NUM when it is a number and CHAR when it is not; called with a type, it answers 1 when the string is of that type and 0 when it is not. The types are about the form of the string, never about its meaning: they ask whether it is a number, a whole number, a string of hexadecimal or of binary digits, a string of letters or of letters and digits, a symbol, or a logical value.

Arguments

[bif.datatype.method]

DATATYPE is a builtin that runs as a String method, and string, its first argument, is the receiver; type becomes the message's argument. string is a string and may be the null string. The argument count is checked by the builtin call rules: one argument is required and two is the most.

say datatype('12') '12'~datatype '12'~datatype('W') datatype('', 'X')
signal on syntax name a
say datatype()
a: say condition('o')~code
signal on syntax name b
say datatype(, 'N')
b: say condition('o')~code
signal on syntax name c
say datatype('1', 'N', 2)
c: say condition('o')~code

[bif.datatype.type]

type selects the test by its first character, in either case, and the characters after the first are not looked at. The letters that select a test are A, B, I, L, M, N, O, S, U, V, W and X, and the digit 9. A type whose first character is another character, including a blank, or a type that is the null string, raises SYNTAX 93.915. The type is checked before the string is examined, so it raises the error for every string, the null string included.

say datatype('12', 'n') datatype('12', 'Number') datatype('12', 'Nonsense'),
    datatype('abc', 'Xyz')
signal on syntax name a

[bif.datatype.omitted]

When type is omitted, DATATYPE answers NUM if the string is a number as the number test defines it, and CHAR if it is not; a type that is omitted behaves as an absent one.

say datatype('  7.5 ') datatype('') datatype('1 2') datatype('12', ) datatype('x1', )

Numbers

[bif.datatype.number]

Type N answers 1 when the string is a number: a string of the whole-number form whose value is within the exponent range of the language. The strings that a number argument rejects with SYNTAX 93.943 are exactly the strings for which N answers 0: the null string, a string of only whitespace, a string with a character that the form does not allow, and a number whose exponent is out of range. The digits of the string are not rounded and NUMERIC DIGITS plays no part.

say datatype(' + 2.50E1 ', 'N') datatype('.5', 'N') datatype('5.', 'N'),
    datatype('- 7', 'N')
say datatype('', 'N') datatype(' ', 'N') datatype('1 2', 'N') datatype('1e', 'N'),
    datatype('0x1', 'N') datatype('..5', 'N') datatype('1' || '0a'x, 'N')
say datatype('1e999999999', 'N') datatype('1e1000000000', 'N'),
    datatype('12.3e999999999', 'N') datatype('1.1e-999999999', 'N')

[bif.datatype.whole]

Type W answers 1 when the string is a number that is a whole number at the current NUMERIC DIGITS. The number is rounded to NUMERIC DIGITS significant digits first. It is whole when the rounded value has no decimal places other than zeros, which are ignored, and its integer part has no more digits than NUMERIC DIGITS, so that a whole value too large to be written in full at that setting is not whole. A string that is not a number is not whole. Zero, where it is a number, is whole however it is written.

say datatype('12', 'W') datatype('1.0', 'W') datatype('1e3', 'W'),

    datatype('1e-3', 'W') datatype('abc', 'W') datatype('', 'W')

[bif.datatype.internal]

Type I answers 1 when the string is acceptable as a whole-number argument, as the conventions' rule gives it (stream positions and BEEP have their own rules). The caller's NUMERIC DIGITS setting plays no part in that rule, so I can answer 1 for a number that W finds too large for the current setting, and 0 for a number that W finds whole because of rounding to a short setting.

Digit strings

[bif.datatype.hex]

Type X answers 1 when the string is a string of hexadecimal digits, as the digit rule defines the digits, and where a conversion function would raise an error for the string, X answers 0: whitespace in the string only where the group rule allows a gap, so that every group after the first has an even count of digits; no whitespace at the start or the end; and a character that is neither a digit nor whitespace. The null string is a string of hexadecimal digits, while a string of only whitespace is not. A string with an odd number of digits is hexadecimal when it has no gap.

say datatype('4a4B', 'X') datatype('4a 4B', 'X') datatype('4 4a4b', 'X'),

[bif.datatype.binary]

Type B answers 1 when the string is a string of binary digits, with the same allowances as X: whitespace only where the group rule allows a gap, so that every group after the first has a count of digits that is a multiple of four, none at the start or the end, and no other character. The null string is a string of binary digits, a string of only whitespace is not. A string with a count of digits that is not a multiple of four is binary when it has no gap.

say datatype('0101', 'B') datatype('1 0101', 'B') datatype('11111 1111', 'B'),
    datatype('010', 'B') datatype('', 'B')

Letters, digits and symbols

[bif.datatype.letters]

The letters here are the 26 letters of the English alphabet in either case, and the digits are 0 to 9; no other character is a letter or a digit, whatever the string holds, accents and the characters of other alphabets included. Type A answers 1 when the string has at least one character and only letters and digits. Type M answers 1 when it has at least one character and only letters. Type L answers 1 when it has at least one character and only lowercase letters, and type U when it has at least one and only uppercase letters. The null string is therefore none of these.

say datatype('aB3', 'A') datatype('aB', 'M') datatype('abc', 'L') datatype('ABC', 'U')
say datatype('aB3', 'M') datatype('aB', 'L') datatype('aB', 'U') datatype('a_b', 'A'),
    datatype('a b', 'M') datatype('A' || 'e9'x, 'A') datatype('é', 'M')
say datatype('', 'A') datatype('', 'M') datatype('', 'L') datatype('', 'U')

[bif.datatype.symbol]

Type S answers 1 when the string is a symbol that SYMBOL does not call BAD: it has at least one character, and each is a letter, a digit, or one of ., !, ? and _, and it has at most 250 characters; a longer string is not a symbol, whatever its characters. The other characters are not symbol characters, among them $, @, #, whitespace and the null character. Case does not matter, and the string is not translated or looked up as a variable.

say datatype('abc', 'S') datatype('A.b', 'S') datatype('5', 'S') datatype('.', 'S'),
    datatype('a!?_', 'S') datatype('1e3', 'S')
say datatype('', 'S') datatype('a b', 'S') datatype('a-b', 'S') datatype('$a', 'S'),
    datatype('a#', 'S') datatype('+5', 'S') datatype('"a"', 'S')
say datatype(copies('a', 250), 'S') datatype(copies('a', 251), 'S'),
    datatype(copies('a', 251), 'V')

[bif.datatype.variable]

Type V answers 1 when the string is a symbol, as type S says, whose first character is neither a digit nor a period. A string that passes is a symbol that can name a variable: a simple one, a stem such as a., or a compound.
