The interrexx Language Specification

DIRECTORY

DIRECTORY([newdirectory])

rexxref: Functions > Built-in Functions > DIRECTORY

DIRECTORY answers the name of the current directory, and with an argument first makes another directory the current one. The current directory is where a relative file name starts: the stream builtins, QUALIFY and the commands the program starts all read it.

The rules here are those of a Unix-like system, where the components of a name are separated by slashes. The names of other platforms are not specified.

Note. The current directory at the start of a program belongs to whoever started it, so the examples name no directory of their own. They build their expected values from the answer of a call without an argument, or use the root directory, /, which every Unix-like system has.

Arguments

[bif.directory.args]

newdirectory is a string, and it is optional. DIRECTORY does not run as a String method: sending the message DIRECTORY to a string raises SYNTAX 97.1. It follows the native call rule, both for the number of arguments, so that DIRECTORY(,) is a call without an argument and DIRECTORY(, 'x') raises SYNTAX 88.922, and for an argument that is an object other than a string, such as .nil or .object~new.

here = directory()
signal on syntax name a
say directory('/', 'x')
a: say condition('o')~code
signal on syntax name b
say directory(, 'x')
b: say condition('o')~code
signal on syntax name c
say directory(.nil)
c: say condition('o')~code
signal on syntax name d
say '/'~directory
d: say condition('o')~code
signal on syntax name e
say directory(.object~new)
e: say condition('o')~code
signal off syntax
say (directory(,) == here) (directory() == here)
say directory(.array~of('/')) directory(.mutablebuffer~new('/usr'))

The result

[bif.directory.get]

A call without an argument answers the full name of the current directory and changes nothing. The name is absolute: it starts with a slash, it has no component of one or two periods, no run of slashes and no slash at the end, except that the name of the root directory is the single slash. Symbolic links in it are resolved. What a call answers after the current directory has been removed is not specified.

here = directory()
say left(here, 1) (directory() == here) (pos('//', here) = 0) (pos('/./', here || '/') = 0)
call directory '/'
say directory()
address system 'mktemp -d' with output stem t.
base = directory(t.1)
call sysmkdir base || '/real'
address system 'ln -s real' base || '/link'
say directory(base || '/link') == base || '/real'
call directory '/'
address system 'rm' base || '/link'
call sysrmdir base || '/real'
call sysrmdir base
say sysisfiledirectory(base)

[bif.directory.set]

A call with an argument that names an existing directory makes that directory the current one and answers its full name, in the form of the rule above. A name that does not start with a slash is taken from the current directory. Components of one and two periods, repeated slashes and a slash at the end are allowed in the argument, and a symbolic link is followed, so the answer can differ from the argument in all of these. The change stays until another call changes it again: ending a routine does not undo it.

here = directory()
parent = directory('..')
base = filespec('N', here)
say directory('/usr/../') directory('//')
say (directory(here || '/') == here) (directory(parent || '//' || base || '/./') == here)
call sub
say directory() == '/'
call directory here
say (directory(parent) == parent) (directory(base || '/.') == here)
exit

return

[bif.directory.fail]

A call with an argument answers the null string, and leaves the current directory as it was, when the argument does not name a directory that can be made the current one: a name that no file has, a name that is a file other than a directory, a directory the program has no permission to enter, and the null string. The null string is a name, not an omitted argument, so it does not ask for the current directory. A name is taken as written: blanks at its start or end are part of it. A '00'x ends the name: the characters after it play no part.

here = directory()
say '[' || directory('/spec-directory-none') || ']' '[' || directory('') || ']'
say '[' || directory('/dev/null') || ']' '[' || directory(' /') || ']' '[' || directory('/ ') || ']'
say directory() == here
say directory('/usr' || '00'x || '/spec-directory-none') directory()

[bif.directory.home]

An argument that is ~ alone, or that starts with ~/, has that ~ replaced by the value of the environment variable HOME, and the result is taken as above. When HOME has the null string as its value, does not start with a slash or names no directory, the call answers the null string and changes nothing. What the call does when HOME has no value is not specified.

call value 'HOME', '/', 'ENVIRONMENT'
say directory('~') directory('/usr') directory('~/') directory('~//tmp')
call value 'HOME', '/spec-directory-none', 'ENVIRONMENT'
say '[' || directory('~') || ']' directory()
call value 'HOME', '', 'ENVIRONMENT'
say '[' || directory('~') || ']' directory()
call value 'HOME', 'usr', 'ENVIRONMENT'
call directory '/'
say '[' || directory('~') || ']' '[' || directory('~/lib') || ']' directory()

[bif.directory.user]

An argument that starts with ~ followed by a name, such as ~user or ~user/lib, has the ~ and the name, up to the first slash or the end, replaced by the home directory of the user of that name, as the system's user database gives it; HOME plays no part. When no user has that name, or that user's home directory cannot be made the current one, the call answers the null string and changes nothing, even when the current directory holds a directory called ~user. The name ./~user reaches that directory.

here = directory()
address system 'mktemp -d' with output stem t.
base = directory(t.1)
call value 'HOME', base, 'ENVIRONMENT'
home = directory('~' || userid())
say (home \== '') (home \== base) (directory() == home)
call directory base
call sysmkdir base || '/~spec_directory_nouser'
say '[' || directory('~spec_directory_nouser') || ']' (directory() == base)
say directory('./~spec_directory_nouser') == base || '/~spec_directory_nouser'
call directory here
call sysrmdir base || '/~spec_directory_nouser'
call sysrmdir base
say sysisfiledirectory(base)

What the current directory affects

[bif.directory.effect]

A change of the current directory is seen by everything that takes a relative name afterwards: QUALIFY puts the new directory in front of a relative name, a stream builtin opens a relative file name in it, and a command started with ADDRESS runs in it.

call directory '/'
say qualify('x') qualify('./y/z')
say stream('spec-directory-none.tmp', 'c', 'query exists') == ''
address system 'pwd' with output stem out.
say out.1
