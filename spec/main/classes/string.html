String is the class of every string of characters: a literal, a number, and the result of any operation that makes text. A program never needs to make one with new, but it can, and it can subclass String to give strings more behavior. String is a subclass of Object and inherits Comparable, so a string also understands the methods of Object.

Most methods of String are the methods that a built-in function runs, such as left and pos. The behavior of each belongs to the page of its function, and one rule lists them, with what changes when one is sent as a message. The operator methods, such as + and ||, belong to the expressions chapter, and one rule lists them too. The class methods that name sets of characters and make strings, and the methods that only the class has, such as caselessEquals, makeArray and [], are specified in full below. Examples that show an error use a small routine try, as the builtin pages do.

[class.string.value]

[class.string.subclass]

A program makes a subclass of String with the directive or with the subclass method of Class. An instance is made with new, takes the characters given there, and has the class of the receiver of new. It is a string wherever a string is wanted, and the class-side methods of String are understood by the subclass. A String method sent to the instance works on the characters of the instance and answers a new string of class String, not an instance of the subclass, and copy, which Object supplies, answers another instance of the subclass. Wherever a string, a number, a logical value or a whole number is read from the instance, as the receiver or as an argument, its own characters are read and none of REQUEST, MAKESTRING and STRING is sent to it (Deviation 109). [class.string.new]

[class.string.makearray]

makeArray answers a new array of strings, the parts of the receiver, and takes at most one argument, the separator, whose string value is taken like that of an argument of new (SYNTAX 88.909 for an object with none). Without a separator, or when it is omitted, the parts are the lines: the text is cut at each line feed, '0A'x, and a carriage return '0D'x right before a line feed is not part of the line. A carriage return alone is part of its line. With a separator the text is cut at each occurrence of the whole separator, found from the left and without overlap, and the case of letters matters; the null string as the separator makes each character a part. The text before the first cut is the first part, so a text that starts with a separator has an empty first part, and a text that ends with one has no empty part after it. A receiver that is the null string answers an array with no part. A subclass instance and a plain string answer the same.

An instance of a subclass of String is read by its own characters wherever a string, a number, a logical value or a whole number is needed, as the receiver and as an argument, in the message form, in the function form and in the operators; REQUEST, MAKESTRING and STRING are not sent to it for that (Deviation 109).
