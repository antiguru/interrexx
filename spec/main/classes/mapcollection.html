The interrexx Language Specification

MapCollection

rexxref: Builtin Classes > Collection Classes > MapCollection Class; Builtin Classes > Collection Classes > MapCollection Class > of (Class Method); Builtin Classes > Collection Classes > MapCollection Class > makeArray; Builtin Classes > Collection Classes > MapCollection Class > putAll

Deviations: D33

MapCollection is the mixin class of the collections that map an index to an item: the directories, the tables, the relations, the sets and the other classes that the class hierarchy lists as inheriting it. It inherits Collection, and so has every method of that page, and it adds three: the class method of, which builds a collection from index and item pairs, and the instance methods makeArray, which answers the indexes where Collection answers the items, and putAll, which copies every entry of another collection in. The mixin also decides how a map is read when it is the argument of a set operation, which the operand rule states.

A class that inherits only MapCollection has to declare put and allIndexes, which are abstract in Collection; the examples use the class store, which keeps its entries in a directory and declares those two, allItems and a string method that lists its entries in index order.

The class

[class.mapcollection.creation]

MapCollection is a mixin class whose superclass is Collection, and queryMixinClass answers 1 for it (the mixin rule). new is not refused and makes an object of the class that received it, as the new rule says. The instance methods that the class declares are makeArray and putAll, and of is declared on the class side: the class and every class that inherits it understand of, and no instance does, so hasMethod('OF') answers 1 for the class and 0 for an instance. Everything else an instance understands it gets from Collection.

c = .mapcollection~new
say c~class~id .mapcollection~queryMixinClass .mapcollection~superclass~id
say .mapcollection~hasMethod('OF') c~hasMethod('OF')
say c~hasMethod('MAKEARRAY') c~hasMethod('PUTALL') c~hasMethod('UNION')

of

[class.mapcollection.of]

of(pair, ...) answers a new object of the class that received it, made by new and holding one entry for each argument: an argument is an array of exactly two items, the index first and then the item, and the entry is the second item stored at the first. The arguments are taken from left to right, so a later pair with the same index replaces the item of an earlier one when the class's put replaces. With no argument the result is an empty collection. A trailing omitted argument counts for nothing. A class that declares no put of its own gets the abstract put of Collection, so .mapcollection~of with a pair raises SYNTAX 93.965.

s = .store~of(.array~of('red', 1), .array~of('green', 2), .array~of('red', 3))

[class.mapcollection.of.sends]

of sends new to the class that received it, with no argument, before it looks at any argument. For each argument in order it then asks the argument what it is and how big, by sending it isA with the class Array; when that answers 1, dimension; when that answers 1, items and then last, whatever items answered; and when both answered a number equal to 2, [] with 2 and then [] with 1, and then put to the new object with the item and then the index. dimension, items and last have no argument. An answer of 0 to isA or to dimension ends the checks of that argument with the error rule's error. What new answers is the result, and init is not sent again. The argument need not be an Array: an object that answers those messages as one does is accepted.

[class.mapcollection.of.error]

Each argument is checked when it is reached, after the pairs before it have been stored. The answers to isA and to dimension are used as logical values, and the argument is accepted when both are 1. putAll

[class.mapcollection.putall]

putAll(source) stores every entry of source into the receiver and answers the receiver. The entries are those of the supplier that source answers to supplier, in the order the supplier gives them, each stored by put with the supplier's item and then its index; an entry of the source whose index the receiver has is stored over by put in the way that put of the receiver decides. source need not be a collection: any object that understands supplier is accepted. The method takes exactly one argument: none raises SYNTAX 93.901 and a second raises SYNTAX 93.902.

s = .store~new
src = .array~of('a', 'b', 'c')
r = s~putAll(src)
say (r == s) '|' s
say s~putAll(.array~of('X'))

[class.mapcollection.deviation.33]

The order in which a hash collection yields its entries is not specified (Deviation 33), and so is not the order in which putAll stores the entries of a directory or another hash collection given as source, nor the order of the indexes that makeArray answers for one. src = .directory~new
src['k1'] = 'first'
src['k2'] = 'second'
src['k3'] = 'third'
s~putAll(src)
say s~items
say s~allIndexes~sort~makeString('L', ',')
say s~allItems~sort~makeString('L', ',')
