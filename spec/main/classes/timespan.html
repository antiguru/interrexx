A TimeSpan is a length of time: a signed count of microseconds, at most 3652058 days and 23:59:59.999999 either way, read as days, hours, minutes, seconds and microseconds. It is the difference of two DateTime moments and what is added to one (the + rule), and it can stand for the offset of a time zone (the offset rule). Its methods answer the parts and the totals of the span, write it as text, make another span from it by addition, multiplication and division, and compare it with another. The class inherits Comparable and Orderable, which give it the comparison operators on top of its own compareTo. Every method that answers another span answers a new instance; only init, sent again, changes one (the new rule). The examples build their spans from fixed values.

The class

[class.timespan.creation]

TimeSpan has the instance methods +, -, *, /, //, %, addDays, addHours, addMicroseconds, addMinutes, addSeconds, addWeeks, compareTo, days, duration, hashCode, hours, init, makeString, microseconds, minutes, seconds, sign, string, totalDays, totalHours, totalMicroseconds, totalMinutes and totalSeconds, and the class methods fromCivilTime, fromDays, fromHours, fromLongTime, fromMicroseconds, fromMinutes, fromNormalTime, fromSeconds and fromStringFormat, besides the new that every class has. It may have private methods besides these; they are not part of this specification. Its superclasses are Object, Comparable and Orderable, in that order. The comparison operators of an instance are those of Orderable, which send compareTo to the receiver (the comparison rule). An instance has no unknown method, so a message that the method search does not resolve raises NOMETHOD, as the error rule of the chapter says; it is not a string either, so a string method such as length raises SYNTAX 97.1.

[class.timespan.value]

An instance holds a count of microseconds, a whole number from -315537897599999999 to 315537897599999999, which is the span from the first to the last microsecond of the years that DateTime covers; no span is outside this range, and a method that would make one raises SYNTAX 40.19 unless its rule gives another error. The count is read as days, hours, minutes, seconds and microseconds by the parts rule, and a negative count is a negative span in all of them. The arithmetic of the class is done in 18 significant digits, whatever NUMERIC DIGITS the program that sends the message has set (the total rule and the rules of the arithmetic methods say where it shows). The string value of an instance is its string text: an instance written by say, or joined to a string by ||, is that text, as the string-value rule says. An instance on which the init of TimeSpan never ran, because the init of a subclass does not forward to it, is the span of 0 (Deviation 131).

Making an instance

[class.timespan.new]

new makes an instance and sends init to it with the arguments it received (the new rule); the init of TimeSpan takes from one argument to five, and the number of them that are given, counted as the count rule says, picks the form. With one argument it is the number of microseconds of the span, a whole number as the form rule and the digits rule read it (Deviation 130), positive or negative. With two arguments they are hours and minutes, with three hours, minutes and seconds, with four days, hours, minutes and seconds, and with five days, hours, minutes, seconds and microseconds; a part that the form does not name is 0. The parts of the multi-part forms are never negative: a span below zero is made by the one-argument form or by negating a span. No argument raises SYNTAX 93.901, and more than five SYNTAX 93.902. An omitted argument inside the list, before a given one, raises SYNTAX 93.903. init is an ordinary message that can be sent again (the init rule): it gives the instance the span that new with the same arguments would make, after the same checks.

[class.timespan.fromtime]

fromNormalTime, fromCivilTime and fromLongTime read a time of day that is written in the form of the option N, C or L of TIME: hh:mm:ss, h:mmam or h:mmpm, and hh:mm:ss.f where f is one to six digits, taken as the leading digits of the microseconds.
