Class is the class of the class objects: every class is an instance of it, or of a subclass of it, which is a metaclass. Its instance methods are therefore what every class object understands: the methods that make and change classes (subclass, mixinClass, define, inherit and the others), that answer questions about a class (id, superClasses, method) and that make objects (enhanced). Class is a subclass of Object, so a class also understands the methods of Object. Its class method new makes a new class.

The chapter index lists how the library classes are related and what new and defaultName do. The method search specifies what define, inherit and the other methods that change a class do to the order in which methods are looked up; this page specifies their arguments, their checks and their errors. A class of the class library accepts none of the methods that change it, as the library rule says. The examples that show an error use a small routine try, as the builtin pages do.

Class methods

[class.class.new]

The class method new of Class makes a class. It is a class method of Class and so of every metaclass, a subclass of Class, and it is not the new that makes the instances of an ordinary class (the Object rule specifies that one). Its first argument is the id of the new class: a string, or an object whose request with the argument STRING answers one, and the null string and a number are allowed. The new class has Object as its superclass, is not a mixin class and not abstract, and is an instance of the class that received new, which is also its metaclass; its package is the package of that class, so .class~new gives a class whose package is the one of the library and a user's metaclass gives one whose package is the package that declares the metaclass. new sends the new class the message init with the arguments that follow the id, in order, and answers the class. The class answers no new of its own: a message new to it raises SYNTAX 97.1, but a subclass of it, made with subclass, has the new of every class. The id is required (SYNTAX 93.901, none), .nil and an object with no string value raise 88.909, and the arguments after the id are those of init, so Class itself, whose init takes none, raises 93.902 for one.

say f~id f~class~id f~superclass~id f~queryMixinClass f~isAbstract
call try 'f~new'
