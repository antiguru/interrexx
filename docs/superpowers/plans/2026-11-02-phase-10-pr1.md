## Review Focus

1. Two racing `connect_or_start` calls end with one daemon.
2. A killed blocked client leaves its queue deletable and the daemon alive.
3. A daemon killed with clients connected: their next request answers a clean error, and the next
   connect starts a new one.
4. A socket file left by a crashed daemon does not block the next start.
5. A client built for another protocol version finds its own socket.

## Task 1: Core

**Files:** create `rust/crates/rexx-rxapi/` with `src/core/{mod,queue,registry,macrospace}.rs`,
`src/message.rs`.

**Interfaces:**
- `pub struct Core`; `Core::new() -> Core`.
- `Core::handle(&mut self, client: ClientId, request: Request) -> Outcome`.
- `pub enum Outcome { Reply(Reply), Parked }`. A parked request's reply arrives from a later call.
- `Core::take_ready(&mut self) -> Vec<(ClientId, Reply)>`.
- `Core::client_closed(&mut self, client: ClientId)`.
- `Core::is_empty(&self) -> bool`: no named queue, registration or macro.
- `Request` and `Reply` carry every operation in the behaviour description, using its return codes.

No sockets, threads or clocks; timestamps arrive in `Request`. Tests are in-process, one per behaviour
section, using the description's values, and pin Review Focus 2 at this level.

## Task 2: Transports

**Files:** `src/transport/{mod,direct,unix}.rs`, `src/message/wire.rs`.

**Interfaces:**
- `pub trait Transport { fn call(&self, request: Request) -> Result<Reply, TransportError>; }`
- `direct::Direct`, `cfg(test)` or behind feature `test-direct`, never in a default build.
- `unix::Unix::connect_or_start(dir: &Path) -> Result<Unix, TransportError>`.
- `PROTOCOL_VERSION: u32`; the socket name includes it.

The directory comes from `REXX_API_DIR`, else `$XDG_RUNTIME_DIR/interrexx`, else a `0700` directory
under the temp directory. Encoding is length-prefixed and hand-written, with no new dependency.

## Task 3: Daemon

**Files:** `src/bin/rxapi.rs`, `src/daemon.rs`.

One thread per client feeding a single owner of `Core` over a channel, and writing replies back. A
lock file held for the daemon's life decides ownership. It exits when no client is connected and
`is_empty`. `rxapi` prints what `rxapi.testGroup` relies on, and `rxapi --stop` stops it.

Tests, each with a private `REXX_API_DIR`, in `tests/daemon.rs`: Review Focus 1, 3, 4 and 5, a
two-process add and blocking pull, and exit when empty.
