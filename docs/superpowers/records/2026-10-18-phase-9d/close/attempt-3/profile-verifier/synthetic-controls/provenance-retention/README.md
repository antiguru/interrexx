This directory retains synthetic verifier-control evidence and does not describe measured interpreter profiles. The original harness did not save numeric process exit statuses, so every recorded actual return code remains null and expected assertions are labeled separately. Seven controls retain their original stdout and stderr files, whose paths and hashes appear in cases.json. The existing-output refusal control discarded its process-local captured channels, and its argv is reconstructed from the saved harness rather than presented as a contemporaneous log. No control or profile was rerun to create this retention record.
