The builtin and error message tables, generated from the checked-in interface tables in data/ and the message texts in messages/.

§Message texts

messages/<major>.tsv holds interrexx’s own text for each error message of one major, one row per message: major<TAB>sub<TAB>text. A text writes insert k as &k (the utility messages of major 999 too, though the source marks theirs %k), and only for a k in the row’s rendered column of data/errors.tsv. A line that is empty or starts with # is a comment. A text has no tab and no line break. The build checks every file: its name is the major of each of its rows, each code is in errors.tsv, no code has two texts, every code has one, and no text uses an insert outside the rendered set. errors::MESSAGES carries these texts.
