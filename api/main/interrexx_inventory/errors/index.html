Functions§

expand
expected with each ⟨M.S¦v1¦v2⟩ replaced by the text of message M.S with the inserts v1, v2, … filled in, and each ⟨M⟩ by the text of the major M on its own. A test writes the message lines it expects with these markers instead of quoting a wording, so that the wording can change without the test: the code and the inserts stay in the expectation.
lookup
render
The text of message with its inserts filled in, in position order. A test that expects a message renders it through this function rather than quoting the text, so that a change of wording alone fails nothing.
substitute
text with &1, &2, … replaced by the values of the same position. A position with no value stays as written.
