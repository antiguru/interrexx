Expand description

A Stream’s own state. The name is kept as the program wrote it, because ~string answers it verbatim; the qualified path is what anything touching the file system uses.

Fields§

§name: Vec<u8>

The name as given, which ~qualify resolves and ~string does not.

§qualified: Box<[u8]>

The name resolved against the interpreter’s current directory, filled in when the stream is initialised so a later DIRECTORY() cannot move an already-named stream.

§standard: Option<StandardStream>

Set by !std_set for STDIN, STDOUT and STDERR, with or without a trailing colon.

§handle: Option<StandardStream>

Set by !handle_set for HANDLE:0, HANDLE:1 and HANDLE:2, which read and write through the standard stream of that number. standard is set with it.

§descriptor: bool

Set by !handle_set for HANDLE:n with any other n, which the name holds: an open reads and writes a duplicate of descriptor n, which shares its file offset and which a close closes alone.

§status: StreamStatus§open: Option<OpenFile>

None until something opens the stream, and again after a close for named files. An owned persistent standard output keeps its duplicate and per-stream positions across close and reopen, gated by status.

§mode: OpenMode§held: Vec<u8>

What a sink-backed standard output or error stream opened without NOBUFFER has written and not yet handed to its descriptor, as OpenFile holds a file’s or an owned stdout alias’s writes.

§local: bool

Set for .local’s .STDIN, .STDOUT and .STDERR, which write where SAY and trace output go and so never hold a write, whatever a reopen’s options say.

§append_extent: u64

The size of the file when an APPEND open opened it, and 0 for any other open: the write position cannot move to a byte within it (rexxref funct.xml, STREAM OPEN APPEND).

impl Clone for StreamState

A copy is an unopened stream carrying the same name: a descriptor cannot be cloned without either sharing a file position or a dup(2) that can fail where Clone cannot. There is no answer to match: ~copy of a stream aborts the reference run (oracle defect, corpus/oracle-crashes.txt entry 13), so this is a licensed divergence rather than a shape being reproduced.
