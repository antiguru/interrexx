pub fn clear_frame_slot(&mut self, frame: SlotFrame, index: usize)

Returns slot index within frame to the unset state, which is what DROP on a simple variable does.

a = 5     ; drop a ; say a   ->  A                 (unset: derived name)
x = .nil            ; say x  ->  The NIL object    (`.nil` is a value)
y = .nil  ; drop y  ; say y  ->  Y                 (unset, not NIL)

pub fn iter(&self) -> impl Iterator<Item = ObjRef> + '_

Yields globals, temps, every live register, every assigned slot and every cell an alias names, across every currently active frame – a popped frame’s slots are already gone, truncated out of slots by pop_slots, so nothing here needs to filter them out again by frame.
