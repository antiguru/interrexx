Heap::collect, with class_refs naming what a live class object keeps alive beyond its body: the class graph a caller keeps outside the heap, which holds a class’s superclasses, mixins and metaclass by handle. pub fn get_mut(&mut self, r: ObjRef) -> Option<&mut Object>

The same holds for Heap::peek_mut.
