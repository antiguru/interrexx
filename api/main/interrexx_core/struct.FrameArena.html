Struct FrameArena 

Source 
pub struct FrameArena { /* private fields */ }
Expand description

The stack of live register frames, reserved and released in LIFO order.

A frame cannot outlive the arena it came from:

ⓘ
use interrexx_core::{FrameArena, FrameBlock};
let escaped = {
    let arena = FrameArena::new(FrameBlock::DEFAULT);
    arena.reserve(1)
};
escaped.get(0);

while the same use inside the arena’s scope compiles:

use interrexx_core::{FrameArena, FrameBlock};
let arena = FrameArena::new(FrameBlock::DEFAULT);
let frame = arena.reserve(1);
assert_eq!(frame.get(0), interrexx_core::ObjRef::NIL);
arena.release(frame);

pub fn is_idle(&self) -> bool

Whether no frame is reserved, of any length: the state a new arena is in, apart from the blocks it keeps.

Such an arena can serve another activity as a new one would. Every cell still holds an ObjRef bit pattern (property 1, and a cell is only ever written an ObjRef), and reserve writes ObjRef::NIL to every register it hands out, so a value left in a cell is neither a root (iter walks only reserved frames) nor any register’s starting value.
