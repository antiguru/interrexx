Module wire 

Source
Expand description

The byte encoding of requests and replies, little-endian and length-prefixed.

A connection opens with hello and welcome. After that each direction carries frames: an 8-byte length of what follows, an 8-byte call number, and a body. Only this crate’s own clients and daemon of one PROTOCOL_VERSION speak it.
