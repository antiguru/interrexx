interrexx_rxapi

Module reserved 

Source
Expand description

Descriptors the interpreter owns for its own use, kept out of a program’s reach.

A program’s SockClose(n) or SysClose(n) names a descriptor by number, and the numbers the process hands out first are the lowest free ones. So that a program closing small numbers cannot close the interpreter’s own descriptors (the timer’s wake socket the signal handler writes to, its deadline timer, the rxapi connection, a running command’s pidfd), each is moved at creation to the lowest free number at or above floor and recorded here; rxsock and rxunixsys answer EBADF for a recorded number, as for a closed one.

The floor is 1000, lowered to 24 below the RLIMIT_NOFILE soft limit where that is smaller, so the interpreter’s descriptors sit above the numbers a program normally reaches and below the limit. Where no number at or above it is free, the descriptor keeps its number and is still recorded.
