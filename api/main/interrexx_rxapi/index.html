inheritance
Which descriptors a child process inherits. On a host that cannot create a descriptor close-on-exec in the same call, a child started by one thread while another thread is between creating a descriptor and setting the flag inherits it. Every descriptor of the process’s own made that way is made under creating, which takes a shared lock, and every child is started under spawning, which takes it exclusively. The lock lives in this crate, the lowest that both the API client and the interpreter build on, so that both take the same one.
macro_file
The saved macrospace file, interrexx’s own layout (Resolution 3): a header of a 16-byte text, an 8-byte signature and an 8-byte count, then per macro its name, position and image, each length-prefixed, little-endian.
