pub fn epoch(&self) -> Epoch

A stamp that changes whenever anything a method lookup, a super-scope resolution or a class’s identity can answer may have changed: every public mutator takes a new one, except the few that touch only the uninit and abstract flags, the dropped methods (Self::take_unnamed_methods, Self::drop_later) and the Rexx-defined mark. Unique across every graph in the process, so a per-site cache filled under one stamp is valid exactly while the graph still answers it.

pub fn class_define(&mut self, class: ObjRef, name: &str, method: MethodId)

Install a class (static) method directly, itself a “special method to allow a class method to be added to a primitive class during image build” (its own doc comment), and one of the two methods stripped before the image ships, alongside ~inheritInstanceMethods. It adds directly to class’s current class behaviour and to its own class-method dictionary (own_class_methods here) – no clear, no rebuild-from-scratch, no cascade to subclasses, unlike every other mutator in this file (the method is added directly and unconditionally to the already-built behaviour, with no rebuild). A class that already has subclasses when this is called would leave them unaware of the new method until their own class behaviour is next rebuilt for an unrelated reason – that gap is consistent with the restriction to image build, before any subclass yet exists. This crate’s own tests use it to seed a mixin’s class-side method before any class inherits it, which is exactly that restriction in miniature.

pub fn class_references(&self, class: ObjRef, out: &mut Vec<ObjRef>)

Every other class class keeps alive: its superclasses (the INHERITed mixins among them), its metaclass, its base class and its owning class. The graph names them by handle, outside the heap, so the collector asks here when it marks a class object; a class reached only this way – a superclass no variable holds – would otherwise be freed under a live subclass. Its subclasses are not among them: that list is weak (see ClassGraph::expunge). Appends nothing for a class the graph does not know.
