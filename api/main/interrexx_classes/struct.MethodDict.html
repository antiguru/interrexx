pub struct MethodDict { /* private fields */ }

A flat name-to-method(s) map, plus the scope ordering a scope-override send needs to resolve correctly.

pub fn merge_methods(&mut self, source: &MethodDict)

Overlay source’s methods on top of this dictionary’s own. Iterating source in reverse priority order and folding each entry in through Self::add_method is what preserves source’s own relative priority after the merge: so the methods get added to this directory in the same relative order that they appear in the source directory.

pub fn same_contents(&self, other: &MethodDict) -> bool

Whether the two hold the same entries under every name and the same scopes, and list them in the same order, which Class~methods answers in: what a cascade over the same inputs in the same order makes.

Source

pub fn merge(&mut self, source: &MethodDict)

Overlay source’s methods and its already-folded scope order on top of this dictionary, which does a method merge (identical to Self::merge_methods) followed by a scope merge, which folds every scope already in source’s own scope_list, in source’s order, into this one via Self::add_scope. This is distinct from Self::merge_methods alone: that merges methods only, and is what an ordinary INHERIT mixin cascade uses (class_graph.rs’s cascade_build) because a mixin’s own ancestors are walked independently by that same cascade. This method is for the one case where the source’s scope history has to come along wholesale instead of being re-derived: the class-behaviour metaclass merge, where a class’s class-behaviour absorbs its metaclass’s already-built instance behaviour verbatim.

pub fn method_names(&self) -> BTreeSet<String>

Every name this dictionary answers to, regardless of which scope supplies it. A name whose highest-priority entry is a tombstone is not one of them, matching Self::has_method. This is what a method-set assertion reads – superClasses/ancestors cannot see a donation that added no scope, but this can.

Source

pub fn defined_entries( &self, ) -> impl Iterator<Item = (&str, ObjRef, MethodId)> + '_

Every defined entry under every name, shadowed ones and ones behind a tombstone included – what a whole-dictionary method walk visits.

pub fn lookup(&self, name: &str) -> Option<(ObjRef, MethodId)>

The highest-priority method for an ordinary (unscoped) send – index 0 of name’s entry list.

pub fn lookup_from_scope( &self, name: &str, start_scope: ObjRef, ) -> Option<(ObjRef, MethodId)>

Resolve name as a scope-override send starting at start_scope, as a super-method lookup does: the first (highest priority) entry whose scope is start_scope itself, or one folded in before it. Returns None if start_scope was never folded into this dictionary, as a scope-table miss does.

Source

pub fn resolve_super_scope(&self, scope: ObjRef) -> Option<ObjRef>

The immediate superscope for scope: the scope folded in just before it, or None for the topmost scope .
