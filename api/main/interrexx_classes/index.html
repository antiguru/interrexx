Enums§

ClassKind
Whether a class was declared with SUBCLASS/plain inheritance or with MIXINCLASS. The only difference this makes is base_class: a Mixin’s is inherited from the class named after MIXINCLASS, a Regular class’s is itself.
InheritRefusal
Why ClassGraph::inherit refused to build the edge, each variant named for the SYNTAX condition ~inherit reports in its place.
MethodSlot
One entry under one name. Several of these can share a name when more than one class in the ancestor chain defines it – that is exactly the case a scope-override (SUPER) send has to distinguish.
