The line a file’s main section starts at: 2 when a file opens with a #! line, which the section’s own source leaves out (r[class.method.newfile.shebang]), and 1 otherwise.

Source

pub fn line_count(&self) -> usize

The number of physical lines, as SOURCELINE() with no argument reports it. A completely empty program has zero lines (the line scan never runs for an empty buffer, so the count stays 0). Empty INTERPRET text still has its one line.

Source

pub fn line(&self, n: usize) -> Option<&[u8]>

The text of physical line n (1-based), with its terminator excluded, or None if n is 0 or past line_count().

Source

pub fn span_bytes(&self, span: Range<usize>) -> Option<&[u8]>

The bytes a token or clause span covers, or None if the span runs past the end of the retained text or backwards.

Source

pub fn join_span(&self, span: Range<usize>) -> Option<Cow<'_, [u8]>>

The bytes a clause span covers with the line terminators inside the span removed, which is the text TRACE prints on a *-* line: a continued clause’s fragments are joined by dropping the terminator between them and keeping every other byte, including the continuation line’s leading blanks and a terminating ;.

Source

pub fn line_span(&self, n: usize) -> Option<Range<usize>>

The line’s content range in the retained text, terminator excluded, or None if n is 0 or past line_count(). line(n) returns exactly &text[line_span(n)?].
