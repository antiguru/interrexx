pub const MAX_EXPR_DEPTH: u32 = 50_000;
Expand description

The parser’s own nesting limit, exported because a caller has to be able to reason about it: it decides which inputs come back as 11.1 rather than as an AST, and it is the number a test or an embedder checks its own depths against rather than hardcoding 50,000 in two places. How many levels of nested expression the parser descends before raising 11.1 (r[expr.index.nesting]) instead of recursing one level deeper. The native stack of the thread the interpreter parses on must hold this many levels: tests/deep.rs recurses to this depth on that thread, so a change that makes a level costlier shows there as an abort.
