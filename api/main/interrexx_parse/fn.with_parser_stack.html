pub fn with_parser_stack<T: Send>(work: impl FnOnce() -> T + Send) -> Result<T>
Expand description

Runs work on a fresh thread with PARSER_STACK_BYTES of stack and waits for it to finish. The closure can borrow its inputs from the caller.

§Errors

Returns an I/O error if the thread cannot be spawned. A parse error returned by the closure is part of the closure’s result.

§Panics

Propagates a panic from the worker to the caller.

§Examples

let line = b"say 'hello'".to_vec();
let program = interrexx_parse::with_parser_stack(|| {
    interrexx_parse::parse_lines(&[&line])
})??;
assert_eq!(program.main.instructions.len(), 1);
