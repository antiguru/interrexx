Expand description

One instruction form: the 35 keyword instructions, plus the four clause shapes that no keyword introduces.

Assignment

name = expr, and also name (op)= expr, whose right-hand side is already the expanded name op expr, its read of name a node of its own before the value’s.

When

Fields

§condition: ExprId
§false_target: Option<usize>

Where control goes when condition is false: the next WHEN, the OTHERWISE, or the enclosing SELECT’s END.

§exit: Option<usize>

Where control goes when this WHEN’s branch finished, which is the instruction after the enclosing SELECT’s END, because one true WHEN ends the whole SELECT. None is the end of this body.
