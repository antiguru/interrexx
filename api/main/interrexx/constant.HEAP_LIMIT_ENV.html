The environment variable that bounds the body bytes the heap may hold (r[env.invocation.heap-limit]): decimal digits, optionally followed by K, M or G for that many binary kilo-, mega- or gigabytes. The empty string is the same as no value, which leaves the heap unbounded. An Invocation::with_heap_limit overrides it.
