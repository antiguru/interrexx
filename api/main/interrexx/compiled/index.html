interrexx

Module compiled 

Source
Expand description

The compiled program image rexxc writes: a #! line and a metadata header layout, with this build’s own magic number and format version, then the SHA-256 digest of everything after it, then the name of the routine the image holds, as a 4-byte little-endian length and its bytes, then the checked source. An image whose bytes after the digest do not give it is refused (r[env.invocation.rexxc.damaged]), so a damaged image does not run. The digest is not keyed: it catches damage, and an image edited on purpose can carry a digest of its own. No compatibility is promised between versions of this crate.
