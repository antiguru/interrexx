impl Invocation

Source

pub fn none() -> Invocation

No argument at all and nothing to read: the state rexx p.rex puts a program in when its stdin is at /dev/null.

Source

pub fn with_arguments(self, arguments: Vec<Option<Vec<u8>>>) -> Invocation

The same invocation, passing arguments (None an omitted one), as RexxStart does, in place of one argument string.

Source

pub fn with_start(self, start: StartType) -> Invocation

The same invocation, calling the program as start says.

Source

pub fn with_address(self, address: Vec<u8>) -> Invocation

The same invocation, with address the initial ADDRESS environment.

Source

pub fn with_exits(self, exits: Vec<(c_int, Vec<u8>)>) -> Invocation

The same invocation, with the system exits exits names, each a function code and the name of a registered exit handler.

Source

pub fn with_classic_thread(self, thread: usize) -> Invocation

The same invocation, run for a RexxStart called on the thread thread.

Source

pub fn with_outside_host(self) -> Invocation

The same invocation, run for a host outside the interpreter that calls it through the API: waits are not refused as unending (Deviation 20).

Source

pub fn with_directory(self, directory: PathBuf) -> Invocation

The same invocation, resolving relative paths against directory.

Source

pub fn with_standard_transient( self, standard_transient: [bool; 3], ) -> Invocation

The same invocation, told which standard descriptors are transient – input, output, error, in that order. A caller that owns real descriptors reads them here; one that does not leaves the default.

Source

pub fn with_environment( self, environment: Vec<(Vec<u8>, Vec<u8>)>, ) -> Invocation

The same invocation, reading and writing environment instead of a copy of the process’s.

Source

pub fn with_argument(argument: Vec<u8>) -> Invocation

One argument string, exactly as supplied – including the null string, which is a present argument and not an absent one.

Source

pub fn with_input(self, input: ProgramInput) -> Invocation

The same invocation, reading .input from input.

Source

pub fn with_sinks(self, sinks: Sinks) -> Invocation

The same invocation, handing the buffered output to sinks as it runs.

Source

pub fn with_deadline(self, deadline: Duration) -> Invocation

The same invocation, abandoned if the run is still executing clauses deadline after it starts.

Source

pub fn with_heap_limit(self, bytes: usize) -> Invocation

The same invocation, holding the heap to bytes of body (r[env.invocation.heap-limit]) whatever crate::HEAP_LIMIT_ENV says.

Source

pub fn with_frame_block(self, frame_block: FrameBlock) -> Invocation

The same invocation, carving register frames from blocks of frame_block. The size is validated when the FrameBlock is built.

Source

pub fn with_switch_mode(self, switch_mode: SwitchMode) -> Invocation

The same invocation, switching activities as switch_mode says rather than when the timer says.

Source

pub fn with_syscargs(self, words: Vec<Vec<u8>>, index: usize) -> Invocation

The same invocation, with .SYSCARGS holding words from index on and the slots below it empty.

Source

pub fn without_syscargs(self) -> Invocation

The same invocation, with no SYSCARGS entry in .local.

Source

pub fn with_default_options(self, directive: Vec<u8>, count: i64) -> Invocation

The same invocation, sending .Package~defaultOptions('D', directive) and then ('C', count) before the program is installed.
