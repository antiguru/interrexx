Expand description

What RexxCreateInterpreter’s options set up, read from the caller’s RexxOption list.

Fields§

§initial_address: Option<Vec<u8>>

INITIAL_ADDRESS_ENVIRONMENT.

§application_data: usize

APPLICATION_DATA, the instance’s applicationData.

§command_handlers: Vec<(Vec<u8>, SentCommandHandler)>

DIRECT_ENVIRONMENTS and REDIRECTING_ENVIRONMENTS.

§registered_environments: Vec<(Vec<u8>, Vec<u8>)>

REGISTERED_ENVIRONMENTS: an environment name and the classic subcommand handler registered under the second name that serves it.

§load_libraries: Vec<Vec<u8>>

LOAD_REQUIRED_LIBRARY.

§registered_libraries: Vec<(Vec<u8>, SentPackage)>

REGISTER_LIBRARY: each a package name and its table, registered before any LOAD_REQUIRED_LIBRARY is loaded.

§external_call_path: Option<Vec<u8>>

EXTERNAL_CALL_PATH: searched after the current directory.

§external_call_extensions: Vec<Vec<u8>>

EXTERNAL_CALL_EXTENSIONS, split at its commas: tried before the default extensions.

§registered_exits: Vec<(c_int, Vec<u8>)>

REGISTERED_EXITS: each a function code and the name of a registered exit handler.

§context_exits: Vec<(c_int, ContextExit)>

DIRECT_EXITS: each a function code and its context handler.
