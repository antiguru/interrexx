interrexx

Module embedding 

Source
Expand description

The embedding entry points over safe values: the classic RexxStart and the instance API’s RexxCreateInterpreter. The librexx exports read the caller’s C structures and write the answers back.

Started
What RexxStart answers: its return code, negative an error number, the result string, its value as a short (None leaves the caller’s untouched), and the image of an in-store source it translated, for instore[1].

rexx_start
Runs start in an interpreter of its own, its output on this process’s standard output and error, and answers as RexxStart does: 0, the result and, where it is a whole number a short holds, its value; or the negated error number of the condition that ended it. A single command argument with a leading blank loses it, and a single command argument //T translates the program without running it, leaving the short alone.
