Form
FormatError
What FORMAT can fail with. Both are error 93 (Incorrect call to method); the interpreter further distinguishes 93.941/93.942, but this crate follows ArithError’s lead and exposes only the number a trapped Rexx program actually sees in RC, using the variant itself to carry the finer distinction for Rust callers. Every raise site lives in this file, so each variant carries the substitution values directly rather than pre-rendered text – message() renders from the generated table on demand, and additional() exposes those same values in the interpreter’s own order (what condition('o')~additional would return).

Functions§

compare
Evaluates a Rexx comparison between two operand strings, as the interpreter would when both operands are ordinary strings (parsed from source, PARSE, or similar) rather than the result of prior arithmetic.
compare_bytes
compare’s byte-slice twin, for a caller holding a Rexx value’s actual bytes rather than an already-checked &str – see this module’s header for why &str cannot carry one. Reduces to compare_decoded with nothing pre-parsed, exactly as compare does.
compare_decoded
compare_bytes, but for a caller that already knows one or both operands’ parsed Number – passing it in skips reparsing bytes for the numeric family, which is the whole reason this entry point exists rather than only compare_bytes. None means “parse from the bytes if a numeric operator needs a value”, which is what both compare and compare_bytes pass for every operand.
compare_numbers
compare_decoded’s numeric arm alone: both operands already parsed, and no bytes at all.
compare_strings
compare_decoded’s two byte-comparing arms alone: the strict family, and the fallback a non-strict operator takes when an operand does not convert.
compare_with_null
compare_strings against the null string, on either side, for the operators that need no ordering: equal by the string rule is all blanks, equal strictly is empty. None for an ordering operator, which compare_strings answers.
whole_i64
Number::whole_value for a value a caller already holds as an i64, where that answer needs no Number built to reach it.
