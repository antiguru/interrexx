mantissa * 10^exponent, with the Number’s own digit count: a trailing zero is a digit here as it is there (1.10 is 110 at -2).

pub fn add(self, other: Scaled, digits: u64) -> Option<Scaled>

Number::add at digits, where no operand is shortened before the addition and the aligned operands fit WIDEST digits; None otherwise. Within those bounds this is the addition’s general path on machine integers: its fast path for an operand too far below the other to reach the result, its alignment adjustment, and its rounding of the raw sum, leading zeros counted.

Source

pub fn mul(self, other: Scaled, digits: u64) -> Option<Scaled>

Number::mul at digits, where no operand is shortened and the rounded product fits WIDEST digits; None otherwise. The product keeps every digit DIGITS allows, trailing zeros included, and the rest round half up on the first one dropped, as the long multiplication’s rounding does.

Source

pub fn div_integer( self, other: Scaled, digits: u64, remainder: bool, ) -> Option<Scaled>

Number::div for %, or for // where remainder is set, at digits, where neither operand is truncated to the working length and both, aligned, fit a u128; None otherwise, a zero divisor and an integer part longer than DIGITS among them, both of which the general path raises. The integer part is the exact one, as the long division stopped at the units digit answers it, and the remainder is the dividend less that many divisors, at the operands’ smaller exponent and rounded to DIGITS.

Source

pub fn order(self, other: Scaled, digits: u64) -> Option<Ordering>

The numeric comparison at digits with FUZZ 0, where both values align within DIGITS digits and so compare exactly; None otherwise.

Source

pub fn format_plain( self, digits: u64, before: Option<u32>, after: Option<u32>, out: &mut [u8], ) -> Option<usize>

Number::format_with at digits with no expp and no expt, written into out, where the value needs no rounding to DIGITS and the result is plain; None otherwise, and wherever before is too narrow (the error is the general path’s to raise) or out is too short. Answers the length written.
