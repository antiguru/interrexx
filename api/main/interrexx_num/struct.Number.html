pub fn format_form(&self, digits: u64, form: Form) -> String

Renders the number the way automatic-conversion display and FORMAT’s defaults do, honouring NUMERIC FORM. Number::format only ever produces SCIENTIFIC; this is the form-aware entry point the brief asks for, implemented as the all-defaults case of Number::format_with so the two can never drift apart.

Source

pub fn write_short_fraction(&self, digits: u64, out: &mut [u8]) -> Option<usize>

Writes into out what Number::format_form answers at digits, for a value with a fractional part that renders exactly and plainly in at most out.len() bytes; None, writing nothing, otherwise.

Exact means no digit is rounded away (the value holds at most digits digits) and plain means no exponent, which is the same in either form. Under those conditions the rendering spells every stored digit and the negative exponent as the point’s position, so parsing it back yields this number’s digits and exponent unchanged.

pub fn trunc(&self, digits: u64, places: u32) -> String

Implements TRUNC(number, places). Truncates, does not round, and – unlike FORMAT – never produces exponential form: TRUNC(1E10) is the eleven-digit integer, not 1E+10.
