pub static METHOD_CONTEXT: MethodContextInterface

The method-context table an extension is handed. A plain initializer nothing patches, so it lives at one address for the process; the members this crate has not written still refuse loudly. A member trusts the context it is handed, so calling one is unsafe:

ⓘ
let mut bare = RexxMethodContext_ {
    threadContext: std::ptr::null_mut(),
    functions: std::ptr::null_mut(),
    arguments: std::ptr::null_mut(),
};
(METHOD_CONTEXT.SetObjectVariable)(&raw mut bare, c"X".as_ptr(), std::ptr::null_mut());
