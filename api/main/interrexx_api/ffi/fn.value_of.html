pub unsafe fn value_of(descriptor: &ValueDescriptor, repr: Repr) -> Value
Expand description

The value descriptor carries, read as the union member repr names.

Safe code can build a descriptor whose written member is narrower than the one repr names, which is why the read is unsafe to ask for:

ⓘ
let narrow = ValueDescriptor {
    value: ValueUnion { value_float: 1.5 },
    r#type: 0,
    flags: 0,
};
let read = value_of(&narrow, Repr::Double);

§Safety

Every byte of the member repr names is initialised: descriptor’s word was written in full, as every union crate::values::descriptor builds is, or that member itself was written.
