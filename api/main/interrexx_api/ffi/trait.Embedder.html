Expand description

What an embedding serves for the instance members that act on a whole instance rather than on a native call: its interpreter is reached by the address of its instance (ThreadTable::instance), from any thread.

Required Methods§

Source

fn terminate(&self, instance: usize) -> bool

Terminate: ends the interpreter whose instance is at instance, answering once it has ended; false where instance is no embedding’s or the interpreter cannot end now.

Source

fn halt(&self, instance: usize) -> bool

Halt: asks every activity of the interpreter to halt; false where instance is no embedding’s.

Source

fn set_trace(&self, instance: usize, on: bool) -> bool

SetTrace: turns external tracing of every activity on or off; false where instance is no embedding’s.
