RedirectorContext

ThreadContext
The thread context an extension is handed, which it may keep for as long as the interpreter runs: it belongs to the activity, and RexxPackageLoader is handed it.
ThreadTable
One thread table, which every ThreadContext built from it links: its data members are one interpreter’s constants. It carries the interpreter’s one instance, which every context linking the table links too (r[native.threads.instance]). A clone addresses the same table; the table’s allocation lives until the last clone, or the last context linking it, is dropped, and the instance’s is never freed. A thread other than the interpreter’s reaches the table through the instance while a clone lives (AttachThread), so clones are shared between threads.
