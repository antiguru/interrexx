Functions§

call_back⚠
RexxCallBack: the label label of the activation that called the running external function, run as an internal function over the argc strings at argv (a null strptr an omitted one). The result goes into result’s buffer where it fits, else into a block RexxFreeMemory releases, and its atoi into rc. A condition the call raises, or an EXIT, ends the external function here: it unwinds to the boundary that called it, which re-raises it.
halt_calling
RexxSetHalt aimed at this thread, which runs a native call of an activity no RexxStart started: that call’s activity halted at its next clause: the activity running on the thread named is the one found. hostemu’s HI command makes this call from its handler. false where this thread runs no native call.
share_session_queue
Where this thread runs a native call, has its interpreter move a session queue it still holds in process to the service (crate::callbacks::Surface::share_session_queue): what a C API operation on the session queue does first, so that it and the program see one queue.
variable_pool⚠
RexxVariablePool: each block of the chain blocks served in turn against the activation that called the running routine, classic function or exit, answering their return codes OR’ed; RXSHV_NOAVL where this thread runs none.
