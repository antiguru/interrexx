Expand description

RexxCallBack: the label label of the activation that called the running external function, run as an internal function over the argc strings at argv (a null strptr an omitted one). The result goes into result’s buffer where it fits, else into a block RexxFreeMemory releases, and its atoi into rc. A condition the call raises, or an EXIT, ends the external function here: it unwinds to the boundary that called it, which re-raises it.

§Safety

A non-null label is NUL-terminated, argv holds argc strings each readable for its length, and a non-null rc and result are writable, result’s non-null buffer for its strlength.
