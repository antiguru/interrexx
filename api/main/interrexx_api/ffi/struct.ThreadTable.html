Struct ThreadTable 

Source 
pub struct ThreadTable { /* private fields */ }
Expand description

One thread table, which every ThreadContext built from it links: its data members are one interpreter’s constants. It carries the interpreter’s one instance, which every context linking the table links too (r[native.threads.instance]). A clone addresses the same table; the table’s allocation lives until the last clone, or the last context linking it, is dropped, and the instance’s is never freed. A thread other than the interpreter’s reaches the table through the instance while a clone lives (AttachThread), so clones are shared between threads.

A table whose contexts’ callbacks from a thread running no native call take requester, and whose data members are constants from the start, before any address of it or of its instance is handed out.

pub fn instance(&self) -> *mut RexxInstance_

The interpreter’s instance, which every context linking this table links, at one address for the rest of the process.

Source

pub fn build_attached_context(&self) -> Option<usize>

The address of a context built as AttachThread builds one for a thread with no activity of this interpreter, on the pending list until a callback through it files it, or None where the table has no requester or the interpreter is gone. It attaches no thread, so the interpreter’s side of an attach can be driven without a foreign one.

Source

pub fn take_pending(&self, address: usize) -> Option<ThreadContext>

The context at address that AttachThread built from this table and no callback has filed yet, taken off the pending list (r[native.threads.attach]), or None where address is no such context. The interpreter files it as an attached activity.
