pub fn methods(context: &str) -> Vec<Method>
Expand description

The C++ methods of context struct context, in the order the header defines them.

The instance and the redirector context have one method per function member of their table. The thread context adds to those the methods of thread_methods. The method, call and exit contexts have one per function member of their own table and forward every thread context method but THREAD_ONLY to their threadContext.

§Panics

If context is not one of CONTEXTS.
