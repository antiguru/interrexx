Module header 

Source
Expand description

The C declarations of include/, generated from the Rust definitions in layout.rs.

Each header in include/ is hand-written text around generated sections. A section opens with the line /* BEGIN GENERATED <name> */ and closes with /* END GENERATED <name> */; splice replaces what lies between with what sections renders. The test headers_are_current (tests/headers.rs) checks every file, and with REXX_HEADERS_REFRESH=1 writes it.

Every type a generated declaration names comes from the tokens of the Rust type through c_type, never from a C string kept beside the Rust one, so a change to a Rust definition changes the header and the ABI dump (tests/abi_dump.rs) measures the two against each other.

The constants come from constants.rs, the exports from exports.rs, and the error codes of oorexxerrors.h from the error table (interrexx-inventory/data/errors.tsv), whose rows sections takes.
