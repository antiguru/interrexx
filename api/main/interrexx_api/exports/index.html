interrexx_api

Module exports 

Source
Expand description

The functions librexx and librexxapi export, as the headers in include/ declare them.

Each export’s Rust type here is the type of its definition: the defining crates (interrexx-capi, interrexx-capi-rxapi) coerce every definition to it at compile time, so a definition whose signature drifts from its declaration does not build. The header generator (header.rs) spells each declaration from the same tokens, and the ABI dump (tests/abi_dump.rs) measures the declared type of every export against the Rust type through a C and a C++ compiler.
