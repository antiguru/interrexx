instance_key
A key for a new interpreter’s handles. Its two low bits are zero, so mixing it in keeps a handle’s tag. It is splitmix64 of a per-process random base plus a counter, with the tag bits cleared: two calls in a process answer the same key with a chance of about 2^-62, and the keys differ from one process to the next.
