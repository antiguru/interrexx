The library whose routine WAIT an embedding instance’s root activity calls: the routine runs wait with the address of the call’s thread context, and returns once it returns. While it runs, a thread attached to that context reaches its call (crate::ffi::attach_current_thread).
loads
Whether the library at path loads at all, which is what separates open_path’s two Ok(None) answers from one another.
names_only
A library named package whose tables name routines and methods and carry no address, for an extension library the interpreter runs in its own code: the interpreter loads, binds and reports it as any library, and runs its own body where a row of it is called. Answers false to NativeRoutineEntry::has_entry_point and NativeMethodEntry::has_entry_point for every row.
