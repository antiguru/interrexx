Function names_only

pub fn names_only(package: &str, routines: &[&str], methods: &[&str]) -> Library
Expand description

A library named package whose tables name routines and methods and carry no address, for an extension library the interpreter runs in its own code: the interpreter loads, binds and reports it as any library, and runs its own body where a row of it is called. Answers false to NativeRoutineEntry::has_entry_point and NativeMethodEntry::has_entry_point for every row.
