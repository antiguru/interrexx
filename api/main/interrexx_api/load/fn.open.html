pub fn open(
    name: &str,
    search: &[PathBuf],
    cwd: &Path,
) -> Result<Option<Library>, Refused>
Expand description

Open the library name names, searching as library names are searched.

search is tried, in order, before the undecorated name, which the loader resolves, and cwd, the interpreter’s current directory, is tried after that. The loader reads LD_LIBRARY_PATH once at process start, so a directory the interpreter learned of afterwards is unreachable through the undecorated attempt and has to be spelled out here; the caller supplies the directories that variable names.

Ok(None) is the answer where no library of that name loads, and where one loads but publishes no RexxGetPackage. Neither is an error here: that decision is left to the caller at both sites.

§Errors

Refused where the package entry asks for a newer interpreter than this one.
