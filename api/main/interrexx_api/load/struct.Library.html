pub fn close(&self) -> bool

Closes the library, after which none of its rows or hooks calls in, and answers whether it closed, which it does not while a call into it is in flight. The file stays mapped until the process exits.

Source

pub fn identity(&self) -> usize

The file the library was loaded from: two libraries loaded from one file while it stays loaded answer the same number, and two from different files different ones. 0 for a library with no dlopen handle of its own.

Source

What an instance other than the one that loaded this library needs to run its unloader and close it, which keeps the file loaded.

pub fn share_mapping(&mut self, unload: &Unload)

Makes this library, loaded from the file unload’s library was loaded from, use that library’s mapping for its rows and hooks instead of its own, which goes. Closing either then stops both, and a close waits out the calls in flight through either.

Keeps the thread context Library::keep_thread_context kept for the rest of the process, for a library that stays loaded after the interpreter that loaded it has ended: the library’s code may call through the context it was handed as long as it is loaded.

pub fn method(&self, name: &[u8]) -> Option<&NativeMethodEntry>

The method row name names, matched without regard to case.

The row is borrowed from self, which is what stops it outliving the mapping its address points into.

pub fn method_index(&self, name: &[u8]) -> Option<usize>

The index of the row Library::method answers. A library’s tables do not change once it is read, so the index names that row for the library’s life.

Source

pub fn routine(&self, name: &[u8]) -> Option<&NativeRoutineEntry>

The routine row name names, found as a routine is found, and borrowed from self for Library::method’s reason.

The spelling is name byte for byte where a row has it, and otherwise that of the first row matching name without regard to case; of rows spelled alike, the answer is the last, which is the one the package load leaves in the table.

pub fn package_routines(&self) -> Vec<(Vec<u8>, &[u8])>

Each upper-cased routine name with the spelling whose row answers it through the package routine table, in the order it puts them: a later row whose name upper-cases alike replaces an earlier one.
