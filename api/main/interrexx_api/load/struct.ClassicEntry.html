pub struct ClassicEntry(/* private fields */);

The entry point of a classic handler: a RexxFunctionHandler, RexxSubcomHandler or RexxExitHandler, as its registry declares it.

pub unsafe fn new(address: *mut c_void) -> Option<ClassicEntry>

The entry at address, or None for null.

§Safety

A non-null address is the entry point of a handler of the C signature the registry it is registered in declares, mapped for every call made through the entry.

pub fn call_function( self, name: &[u8], arguments: &[Option<&[u8]>], queue: &[u8], ) -> Option<ClassicResult<usize>>

Calls a RexxFunctionHandler with name, arguments (None an omitted one) and the current queue’s name: each string NUL-terminated beyond its length, and the result in a DEFRXSTRING buffer the handler may replace with a block free releases. None where a RexxCallBack the handler made ended it, unwinding through it, with the condition or EXIT kept by the host.

pub fn call_subcom(self, command: &[u8]) -> (ClassicResult<c_int>, u16)

Calls a RexxSubcomHandler with command, answering its return code, its flags and its result.
