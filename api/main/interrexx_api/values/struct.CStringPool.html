Struct CStringPool 

Source 
pub struct CStringPool { /* private fields */ }
Expand description

The terminated copies a call’s CSTRING conversions point at.

A CSTRING’s lifetime is the call, and that could be achieved by rooting the string object and pointing into it. That is not open here: a Rexx string carries no terminator, and the arena moves nothing but reallocates the slot vector, so no address inside the heap survives an allocation. The pool owns its copies instead, so a collection cannot free them, and each one is a separate boxed slice, so growing the pool does not move a pointer already handed out. Dropping the pool is what ends the lifetime, and that is the end of the call.

pub fn intern(&mut self, bytes: &[u8]) -> CSTRING

A pointer to a terminated copy of bytes, valid until CStringPool::clear or the pool is dropped.

Bytes are copied verbatim, so an embedded zero truncates the string an extension reads, which is what pointing into string data does too. Each call answers a fresh copy at its own address.

Source

pub fn intern_for(&mut self, object: ObjRef, bytes: &[u8]) -> CSTRING

CStringPool::intern keyed on the object the bytes came from, so that asking twice answers one address.

StringData hands out an interior pointer to a non-moving object, so the same address is answered for the same object however often it is asked. object is what makes that hold here; the bytes are read again only when the pool has no copy for it yet.
