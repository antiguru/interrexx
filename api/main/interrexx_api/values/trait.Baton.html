Expand description

The right to touch a host’s state, which one thread holds at a time

Required Methods§

Source

fn take_unless_held(&self) -> bool

Takes the baton unless this thread holds it, waiting for it if another thread does, and answers whether it took it.

Source

fn release(&self)

Gives up the baton this thread holds.

Source

fn held_here(&self) -> bool

Whether this thread holds the baton.

Provided Methods§

Source

fn host(&self) -> Option<NonNull<dyn Host>>

The host lent with the baton this thread holds, where it was lent one; valid while this thread holds the baton.

Source

fn take_for(&self, context: usize) -> TakeFor

Baton::take_unless_held for a thread running no native call of the host’s, with the activity whose thread context is at context running while this thread holds it. TakeFor::Refused where the host has ended, or ends while this thread waits: nothing is taken.

Source

fn ended(&self) -> bool

Whether the host has ended, so a request (Baton::post_halt, Baton::post_trace) is not posted.

Source

fn ending(&self) -> bool

Whether the host’s end has begun, so a callback from a thread running none of its native calls is refused and a thread attaches to nothing. It begins no later than Baton::ended.

Source

fn refuses_foreign(&self) -> bool

Whether the host refuses a callback from a thread running none of its native calls, which then does nothing and takes no baton.

Source

fn refuses_attach(&self) -> bool

Whether the host refuses a thread running none of its native calls that attaches, which then attaches to nothing and takes no baton.

Source

fn detach_activity(&self, context: usize) -> bool

The last DetachThread of the attached activity whose thread context is at context: the host ends that activity, answering whether it did. A host that has ended, or files no such activity, ends nothing.

Source

fn post_halt(&self)

Asks every activity of the host to halt (r[native.threads.halt]), from any thread and without taking the baton: the request is served at the holder’s next boundary. A host that cannot be asked does nothing.

Source

fn post_trace(&self, on: bool)

Asks every activity of the host to turn external tracing on or off, served as Baton::post_halt is.
