fn set_object_variable(&mut self, name: &[u8], value: Option<ObjRef>)

Binds name in the running method’s own scope pool, or returns it to the uninitialised state for a value of None.

name is the extension’s own spelling: the interpreter upper-cases it and refuses one that is not a variable name, and both belong to the interpreter rather than to the boundary. The scope is the method’s, not the receiver’s class: a subclass method’s expose CSELF reads an unset variable where the defining class’s reads the pointer.

fn locals(&mut self) -> &mut Table

The local-reference table of the native activation this host is serving, which is where a handle handed to an extension is registered and where the collector reads it back from.

The table lives behind the host rather than beside it so that a collection a callback triggers can see it, and so that an implementation holding the table inside itself needs no second mutable borrow of that same object: the activation both serves the context and owns the save list.
