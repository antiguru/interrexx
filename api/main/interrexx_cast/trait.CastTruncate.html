Trait CastTruncate

pub trait CastTruncate<T> {
    // Required method
    fn cast_truncate(from: T) -> Self;
}
Expand description

A conversion to a narrower integer of the same signedness that keeps the low bits: two’s complement wrapping, as for a hash or a fixed-width field.

Required Methods§
