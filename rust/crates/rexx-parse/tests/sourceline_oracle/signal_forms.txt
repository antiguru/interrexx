   tests/trace_oracle/controlled_loop.rex.










   `signal past_select` is the identical unwind through

   SIGNAL's own design depends on, and this is its witness.

   SIGL: every successful transfer below also prints
   it, pinning that a control transfer sets SIGL to its own line as a plain
   decimal value, not a NUMERIC-DIGITS-bound one.

   What this program's differential run pins: SIGNAL unwinds a DO or a
   SELECT unconditionally (the construct's own later iterations/branches and

   with no `>>>` line (it produces nothing, unlike CALL's dynamic form or
   RETURN with a value), SIGNAL VALUE traces its own `>K>   "VALUE" => text`
